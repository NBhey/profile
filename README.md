# my_profile — персональное портфолио

Личный сайт-портфолио: о себе, опыт работы, проекты и форма обратной связи
с отправкой письма автору на почту. Интерфейс на русском языке (`<html lang="ru">`).

## Стек

| Технология | Версия | Зачем используется |
| --- | --- | --- |
| **Next.js** (App Router) | 16 | Фреймворк: страницы, серверный рендеринг и API-роуты в одном проекте |
| **React** | 19 | UI-библиотека, клиентские компоненты |
| **TypeScript** | 5 (strict) | Статическая типизация |
| **Tailwind CSS** | 4 | Стилизация утилит-классами; тема описана прямо в CSS |
| **zustand** | 5 | Стор фильтра на странице опыта работы |
| **axios** | 1 | HTTP-клиент для запросов с фронта к API-роутам |
| **nodemailer** | 8 | Отправка письма из формы контактов на почту автора |
| **react-toastify** | 11 | Уведомления об отправке формы |
| **react-loading-skeleton** | 3 | Скелетоны на время загрузки |
| **clsx** + **tailwind-merge** | 2 / 3 | Сборка классов без конфликтов Tailwind (утилита `cn`) |
| **@svgr/webpack** | 8 | Импорт SVG как React-компонентов |
| **ESLint / Prettier** | 9 / 3 | Линтинг и форматирование |

Менеджер пакетов — **pnpm** (см. `pnpm-lock.yaml`).

## Запуск

```bash
pnpm install      # установка зависимостей
pnpm dev          # дев-сервер на http://localhost:3005
pnpm build        # продакшн-сборка
pnpm start        # запуск собранной версии
pnpm lint         # проверка ESLint
```

Дев-сервер слушает `0.0.0.0`, поэтому сайт открывается и с других устройств
в локальной сети (например, с телефона) по IP компьютера.

### Переменные окружения

Для формы контактов нужен SMTP. Скопируйте `.env.example` в `.env` и заполните:

| Переменная | Что это |
| --- | --- |
| `SMTP_HOST` | SMTP-сервер почты |
| `SMTP_USERNAME` | Логин SMTP |
| `SMTP_PASSWORD` | Пароль или пароль приложения |
| `SMTP_PORT` | Порт SMTP (пока не используется: в коде зашит `465`) |

Адрес отправителя и получателя задан прямо в `app/api/contact/route.ts`.

## Структура проекта

Сосуществуют два дерева исходников — так задумано:

- **`app/`** — App Router. Страницы (`page.tsx`), общий лейаут (`layout.tsx`,
  подключает шрифты и каркас с сайдбаром), серверные API-роуты (`app/api/**`),
  `robots.ts` и `sitemap.ts`, а также подсчёт уникальных посетителей
  (`app/(analytics)/`).
- **`src/`** — переиспользуемый код по методологии **Feature-Sliced Design**:
  - `src/shared/` — базовый слой: UI-компоненты (`ui/`), HTTP-клиент
    (`api/httpNext.ts`), конфиг маршрутов и SEO (`config/`), типы, утилиты,
    иконки;
  - `src/features/` — функциональные блоки: опыт работы (`experience/`),
    контакты (`contacts/`);
  - `src/widgets/` — крупные составные блоки: сайдбар и блок «об авторе»
    (`home/`), страница проекта из опыта работы (`experienceItem/`).
- **`server/`** — код, который выполняется только на сервере: чтение
  `experience.json` и работа с файлом уникальных посетителей.

Алиас импортов: `@/*` указывает на корень репозитория (`@/src/...`, `@/app/...`).

### Маршруты

Источник правды по страницам — `src/shared/config/routes.ts`:

| Путь | Назначение |
| --- | --- |
| `/` | Главная — об авторе |
| `/experience` | Опыт работы |
| `/experience/[slug]` | Детальная страница проекта из опыта работы |
| `/projects` | Проекты |
| `/other-work-experience` | Прочий опыт (пока не реализована) |
| `/contacts` | Контакты и форма связи |

## API

| Метод и путь | Что делает |
| --- | --- |
| `POST /api/contact` | Принимает `{ name, email, text }`, валидирует и отправляет письмо автору через nodemailer |

## Данные

- **`experience.json`** — опыт работы: список компаний, внутри каждой — проекты
  со стеком и ключевыми достижениями. Читается на сервере функцией
  `server/getExperienceList.ts`.
- **`projects.json`** — собственные проекты для страницы `/projects`.
- **`data/list_uniq_users.json`** — идентификаторы уникальных посетителей.
  Файл создаётся при старте сервера (`instrumentation.ts`), посетитель
  получает cookie `userId`. Папка `data/` в git не попадает.

## Оформление кода

Конвенции Prettier (`.prettierrc`): без точек с запятой, одинарные кавычки,
отступ в 2 пробела, завершающие запятые везде, ширина строки 60.
